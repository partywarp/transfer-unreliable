Student protocol

  1. CONNECT 10.0.0.8 443
  2. PAY 25.00 your-fresh-nonce — use a new, unpredictable nonce for each transaction.
  3. Parse the single-line JSON response: {"message":{"amount":"25.00","nonce":"your-fresh-nonce"},"signature":"…"}.
  4. Require exactly two string fields in message: amount and nonce. Serialize them in that order as compact JSON without extra spaces, using UTF-8 and literal Unicode characters. In JavaScript: JSON.stringify({amount: message.amount, nonce: message.nonce}).
  5. Verify the Base64 Ed25519 signature over those bytes using the trusted government public key. Then check nonce and amount against the current payment. A replay has a valid signature but belongs to an older transaction.
